## Open issue

`logo.png` has no transparency. Two ways to fix it, in order of preference:

1. Re-export a transparent PNG from whichever logo maker produced it — the
   account that made it should still offer the transparent variant.
2. Failing that, key the grey background out. The background is a gradient
   rather than a flat colour, so expect fringing around the white script.

Do not substitute `splogo.png` to get transparency: it is a watermarked
preview and using it on a live store is both visibly wrong and a licensing
problem.
